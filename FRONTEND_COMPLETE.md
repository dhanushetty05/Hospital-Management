## 🚀 How to Use

### 1. Make sure backend is running:
```bash
cd backend
npm run dev
```

### 2. Make sure data is seeded:
```bash
cd backend
npm run seed
```

### 3. Frontend should auto-reload

If not, restart:
```bash
cd frontend
npm run dev
```

### 4. Open browser:
```
http://localhost:5173
```
